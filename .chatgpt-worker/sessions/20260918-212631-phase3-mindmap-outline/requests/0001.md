# Phase 3: 2D MindMap Infinite Canvas & Synchronized Outline View

## Overview
In this third phase of **MarginGraph**, build the core spatial thinking and synthesis engine: the infinite 2D MindMap Canvas, automatic tree layout, floating cards, inter-card relation arrows, and the synchronized hierarchical Outline sidebar. This completes the signature dual/triple-view reading and mind-mapping workflow of MarginNote 3.

## Acceptance Criteria
1. **Tree Layout & Canvas Geometry (`Sources/MarginGraphCore/MindMap/TreeLayout.swift`)**:
   - Calculates layout for hierarchical note cards:
     - Horizontal tree layout (root on left, branches expanding to the right).
     - Computes node frames `(origin, size)` preventing overlapping branches.
     - Respects `isFolded`: when folded, subtrees are collapsed and hidden.
     - Computes smooth cubic Bézier connector paths between parent and child nodes.
     - Computes connector paths and arrowheads for inter-card relation links (`CardLink`).
   - `CanvasViewport`:
     - Tracks `panOffset: CGPoint`, `zoomScale: CGFloat` (clamped 0.1 to 3.0).
     - Methods `screenToCanvas(_ point: CGPoint)` and `canvasToScreen(_ point: CGPoint)`.
     - `zoomToFit(nodes: [CGRect])` calculating bounding box and centering scale.

2. **Interactive 2D MindMap Canvas (`Sources/MarginGraphCore/MindMap/MindMapCanvasView.swift` & `CardNodeView.swift`)**:
   - Infinite 2D pannable and zoomable canvas:
     - Subtle grid rendering.
     - Gestures: pan/scroll, pinch-to-zoom, click background to deselect.
     - Mini-map navigator widget in the corner showing canvas overview and visible viewport.
   - Card Node rendering (`CardNodeView`):
     - Card styling with color accent bar (`colorIndex`).
     - Card title and excerpt quote preview.
     - Thumbnail image preview for rect excerpts (`highlightPicHash` loaded from `MediaStorage`).
     - Tag chips (`tags`).
     - Fold/unfold toggle button on branches with child nodes.
     - Selection state with highlight border.
   - Node interactions:
     - Dragging cards to reposition (free-floating nodes) or reparent onto another node.
     - Clicking a card notifies selection coordinator to center the PDF viewer on the card's excerpt.
   - Inter-card relation links:
     - Draws curved relation lines with arrowheads between linked cards.

3. **Synchronized Hierarchical Outline (`Sources/MarginGraphCore/Views/OutlineSidebarView.swift`)**:
   - Tree list view showing the notebook hierarchy:
     - Indented hierarchical rows for parent/child cards.
     - Disclosure chevrons for folding/expanding.
     - Actions: Indent (Tab / make child), Outdent (Shift-Tab / promote to sibling), delete, reorder.
     - Search & filter toolbar: filter by keywords, tags (`#tag`), and color index.
     - Two-way sync: clicking a node in the outline highlights and centers the card on the 2D MindMap canvas AND scrolls the PDF to the excerpt.

4. **Multi-Pane Workspace Layout (`Sources/MarginGraphApp/`)**:
   - Toolbar view mode switcher:
     - 1-view: MindMap only OR Document only.
     - 2-view: Split view with Document on left, MindMap on right.
     - 3-view: Outline sidebar on left, Document in center, MindMap on right.
   - Unified selection coordinator:
     - Selecting a card in MindMap or Outline highlights the excerpt in the PDF.
     - Clicking an excerpt in the PDF highlights the card in the MindMap and Outline.

5. **Unit Tests (`Tests/MarginGraphCoreTests/MindMapTests.swift`)**:
   - Tests:
     - Tree layout geometry calculation for multi-level hierarchy (ensuring child nodes are offset to the right and do not overlap).
     - Folded branch calculation collapses children.
     - Canvas viewport coordinate conversion round-trip.
     - Tree structure modifications (indenting/reparenting cards in `Database`).
