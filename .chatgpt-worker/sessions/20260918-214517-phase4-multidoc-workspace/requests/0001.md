# Task: Phase 4 — Multi-Document Study Sets, Multi-Pane Workspace & Exporters

## Goal
Implement full multi-document study set functionality, document tab switching, bidirectional card-to-PDF navigation, workspace view modes (1-view, 2-view, 3-view), MarginNote 3 import action, and Markdown / OPML exporters.

## Requirements

### 1. Multi-Document Support in Topics & Database
In `Sources/MarginGraphCore/Database.swift` (or extension `Database+StudySet.swift`):
- `func addDocument(to topicId: UUID, md5: String) throws`: Appends MD5 to topic's `bookMD5List` (if not already present) and persists.
- `func removeDocument(from topicId: UUID, md5: String) throws`: Removes MD5 from topic's `bookMD5List` and persists.
- `func documentsForTopic(id: UUID) throws -> [Document]`: Returns all `Document` records matching the MD5s in the topic's `bookMD5List`.

### 2. Exporters (`Sources/MarginGraphCore/Export/`)
Create `Sources/MarginGraphCore/Export/MarkdownExporter.swift` and `Sources/MarginGraphCore/Export/OPMLExporter.swift`:
- `MarkdownExporter.export(topic: Topic, cards: [NoteCard]) -> String`:
  - Exports the card hierarchy as a clean Markdown document with headers for root cards, bullet indentation for child cards, blockquotes for `highlightText`, paragraphs for `notesText`, `#tags`, and relation links.
- `OPMLExporter.export(topic: Topic, cards: [NoteCard]) -> String`:
  - Exports the card hierarchy as standard OPML 2.0 XML with nested `<outline text="..." _note="...">` nodes, suitable for OmniOutliner / MindNode.

### 3. Multi-Document Workspace & View Modes (`Sources/MarginGraphApp/` and `Views/`)
Update `Sources/MarginGraphApp/MarginGraphApp.swift`:
- **View Modes**:
  - Add an enum `WorkspaceViewMode: String, CaseIterable, Identifiable`:
    - `.threeView`: Outline + MindMap + PDF Reader
    - `.splitView`: MindMap + PDF Reader
    - `.mindMapOnly`: MindMap Canvas only
    - `.readerOnly`: PDF Reader only
  - Add a segmented control / toolbar buttons to toggle between these modes, with keyboard shortcuts (`Cmd+1` for Reader, `Cmd+2` for Split, `Cmd+3` for 3-View).
- **Multi-Document Tab Bar**:
  - When the selected topic has multiple documents in `bookMD5List`, display a document tab bar above the PDF Reader allowing seamless switching between books.
  - Add an "Attach Document..." button (`+`) allowing the user to pick an existing document in the database or open a new PDF to attach to the current study set.
- **Synchronized Navigation**:
  - When selecting a card in the MindMap or Outline sidebar:
    - If `card.bookMD5` matches a document in the study set and is different from the currently displayed document, automatically switch the active tab to that document.
    - If `card.startPage` is present, scroll the PDF reader to that page and highlight the excerpt bounds.
- **Import / Export Actions**:
  - In the toolbar / menu, add:
    - "Import MarginNote 3...": opens NSOpenPanel to select a `MarginNotes.sqlite` database or folder, or imports from standard App Support location if available.
    - "Export to Markdown...": exports current study set to `.md`.
    - "Export to OPML...": exports current study set to `.opml`.

### 4. Concurrency & Swift 6 Safety
- All closures passed to `Array.sorted(by:)` or non-isolated functions in SwiftUI Views must be `nonisolated` or static `Self.method` so Swift 6 concurrency does not flag actor isolation errors.
