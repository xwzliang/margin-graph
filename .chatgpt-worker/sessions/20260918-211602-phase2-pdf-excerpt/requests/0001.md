# Phase 2: PDF Document Viewer & Excerpt Engine

## Overview
In this second phase of **MarginGraph**, build the native macOS PDF reading and excerpting engine using Apple's `PDFKit` and CoreGraphics. Users can open PDFs, navigate pages and TOC outlines, highlight text or drag marquee boxes to create visual/textual excerpts, save cropped excerpt images to media storage, and navigate bidirectionally between note cards and PDF locations.

## Acceptance Criteria
1. **Media Storage (`Sources/MarginGraphCore/MediaStorage.swift`)**:
   - Manages media assets (cropped excerpt screenshots, images).
   - Stores files in `~/Library/Application Support/MarginGraph/media/` (or custom folder / temporary URL for tests).
   - Method `saveImage(_ data: Data, format: String) throws -> String` returns content hash / filename.
   - Method `loadImage(hash: String) -> Data?`.
   - Method `imageURL(hash: String) -> URL`.

2. **PDF Engine & Coordinate Transformation (`Sources/MarginGraphCore/PDF/`)**:
   - `PDFDocumentManager`:
     - Loads a PDF from URL using `PDFKit.PDFDocument`.
     - Computes MD5 hash of the PDF file.
     - Extracts document title, total page count, and outline table of contents (`PDFOutline` hierarchy).
     - Renders a page thumbnail image for a given page index.
     - Crops a rect from a specific page and exports it as PNG image `Data`.
   - `PDFExcerpt`:
     - Represents an excerpt selection on a PDF: `bookMD5: String`, `pageIndex: Int`, `bounds: CGRect`, `text: String`, `croppedImageData: Data?`.
   - `ExcerptCoordinator`:
     - Creates a `NoteCard` from a `PDFExcerpt` within a given `topicId`.
     - Automatically saves any `croppedImageData` to `MediaStorage` and assigns `highlightPicHash`.
     - Saves the card into `Database`.

3. **macOS PDF Reader View (`Sources/MarginGraphCore/PDF/PDFReaderView.swift` / AppKit integration)**:
   - SwiftUI / AppKit `NSViewRepresentable` wrapping `PDFKit.PDFView`:
     - Configured with display mode (single page or continuous scroll), autoScales.
     - Selection tool mode:
       - `.textSelection`: standard linear text selection with highlight color selection.
       - `.rectMarquee`: interactive drag-box to crop any diagram, formula, or text area on a page.
     - Visual highlights: renders custom highlight overlays or `PDFAnnotation`s matching cards stored for this document.
     - Jump coordinator: programmatically navigates and centers the view on a specified `(pageIndex, CGRect)`.

4. **App Integration (`Sources/MarginGraphApp/`)**:
   - Update `MarginGraphApp.swift` / views to support:
     - Opening a PDF file via file picker or selecting an existing imported document.
     - Split reader interface: PDF viewer on main pane + sidebar showing excerpts / cards for the active document.
     - Selecting an excerpt card in the sidebar highlights and scrolls the PDF to that exact page and bounding box.
     - Selection bar: tool picker (Text Select vs Rect Marquee) and color picker.

5. **Unit Tests (`Tests/MarginGraphCoreTests/PDFTests.swift`)**:
   - Programmatically generates a synthetic test PDF using `CGContext` / CoreGraphics with test text and shapes.
   - Tests:
     - PDF document loading, page counting, and MD5 computation.
     - Text extraction and rect cropping to PNG data.
     - `MediaStorage` saving and loading.
     - `ExcerptCoordinator` creating and saving a `NoteCard` with valid bounds and media hash into the `Database`.
     - Verifies round-trip query from `Database` matching the excerpt card.
