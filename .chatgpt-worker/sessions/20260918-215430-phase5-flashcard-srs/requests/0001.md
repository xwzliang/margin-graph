# Task: Phase 5 — Flashcard Review Mode (SRS), Deep Linking & Anki Export

## Goal
Implement the complete MarginNote 3 flashcard review workflow (full-screen SRS active recall, cloze masking, SM-2 grading, card-in-context jump), deep linking URL scheme handling (`margin-graph://`), and Anki deck export.

## Requirements

### 1. Cloze Parsing & SRS Review Models
In `Sources/MarginGraphCore/SRS/` (or `Sources/MarginGraphCore/`):
- `ClozeParser`:
  - Parses text containing clozes formatted as `{{c1::text}}` or `{{text}}` or `[...]`.
  - Masks clozes on card question (`[...]`), reveals text on card answer.
- `Database+SRS.swift`:
  - `func dueCardsForTopic(id: UUID, date: Date = Date()) throws -> [NoteCard]`
  - `func recordCardReview(id: UUID, quality: Int) throws -> ReviewItem`:
    - Reads existing `ReviewItem` (or creates default item for card if none exists).
    - Calls `SRSEngine.calculate(item:quality:)`.
    - Persists updated `ReviewItem` via `Database.insertReviewItem`.

### 2. Full-Screen Flashcard Review UI (`Sources/MarginGraphCore/Views/FlashcardReviewView.swift`)
SwiftUI modal or full-sheet view:
- **Card Presentation**:
  - Front (Question): Title, cloze-masked excerpt quote, image thumbnail (if excerpt has `highlightPicHash`), book title/page tag.
  - "Show Answer" button (or Spacebar / click).
  - Back (Answer): Unmasked text, notes text, tags, and a "Jump to PDF" button to open the excerpt in the document.
- **Grading Controls**:
  - 4 buttons matching SM-2 rating standards:
    - `Again` (1, red) - repeats soon
    - `Hard` (2, orange) - shorter interval
    - `Good` (4, green) - standard interval
    - `Easy` (5, blue) - longer interval
  - Keyboard shortcuts `1`, `2`, `3`, `4` or `Space` to advance.
- **Session Stats & Summary**:
  - Progress bar showing `Card X of Y`.
  - Upon finishing the queue, displays celebration summary with reviewed count, accuracy, and next due forecast.

### 3. Deep Linking (`Sources/MarginGraphCore/DeepLink/DeepLinkHandler.swift`)
- Deep link parser and router:
  - `margin-graph://note/<card_uuid>`: returns `.openCard(cardId: UUID)`
  - `margin-graph://topic/<topic_uuid>`: returns `.openTopic(topicId: UUID)`
- Generates deep link URL for any card (`card.deepLinkURL -> URL`).
- In `MarginGraphApp.swift`, adds `.onOpenURL` to navigate directly to the target notebook, document, and card.

### 4. Anki Exporter (`Sources/MarginGraphCore/Export/AnkiExporter.swift`)
- `AnkiExporter.export(topic: Topic, cards: [NoteCard]) -> String`:
  - Generates tab-separated text suitable for Anki import with fields:
    `Front\tBack\tTags\tSourceBook\tPage`

### 5. App Integration (`Sources/MarginGraphApp/MarginGraphApp.swift`)
- Adds a "Review Flashcards" (`Cmd+R`) button in toolbar with badge of due cards count.
- Adds "Copy Deep Link" context menu item on cards in Outline and MindMap.
- Adds "Export to Anki (TSV)..." option to File menu.
