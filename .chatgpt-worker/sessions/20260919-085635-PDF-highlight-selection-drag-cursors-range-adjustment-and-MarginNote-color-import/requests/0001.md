# Task: Implement PDF Highlight Click Selection, Handle Cursors for Range Adjustment, and MarginNote Color Import

## Context & Requirements

In MarginNote 3, the interaction between the PDF and the MindMap is tightly coupled:
1. **PDF Highlight Click to Select & Focus Card**:
   - When the user clicks an existing highlight on the PDF, the corresponding note card in the MindMap view must be automatically selected/focused (highlighted with the blue dotted/dashed line border, and the canvas centers on the card).
2. **Two Cursors at Start and End of Highlight for Range Adjustment**:
   - When a note is active/selected on the PDF, two cursors (drag handles) appear on the PDF:
     - One handle at the beginning of the highlight (start of first line).
     - One handle at the end of the highlight (end of last line).
   - The user can click and drag either cursor to expand or shrink the highlighted region.
   - While dragging, the highlighted line rects update live between the two handles.
   - Upon release (`mouseUp`), the newly highlighted text is extracted from the PDF (`page.selection(from:to:)`) and automatically updates the note card's content in the MindMap view and in the database.
3. **MarginNote Database Color Setting Import & Usage**:
   - In MarginNote SQLite databases (`MarginNotes.sqlite`), note color is NOT stored in `ZCOLORINDEX` (which doesn't exist in `ZBOOKNOTE`). It is stored in the `ZHIGHLIGHT_STYLE` column (e.g. `mbooks-annotation0`, `mbooks-annotation1`, `mbooks-annotation2`, `mbooks-annotation1c`, etc.).
   - The trailing character of `ZHIGHLIGHT_STYLE` is a hexadecimal digit `0...f` (0 to 15) representing the note's `colorIndex` (0 to 15).
   - Update `MarginNoteImporter.swift` to extract `colorIndex` from `ZHIGHLIGHT_STYLE` if `ZCOLORINDEX` / `ZCOLOR` is absent or 0:
     ```swift
     var colorIndex = Int(first(row, ["ZCOLORINDEX", "ZCOLOR"]) ?? "") ?? -1
     if colorIndex < 0 || colorIndex == 0 {
         if let style = first(row, ["ZHIGHLIGHT_STYLE", "ZHIGHLIGHTSTYLE", "ZSTYLE"]) {
             if let last = style.last, let hex = Int(String(last), radix: 16) {
                 colorIndex = hex
             }
         }
     }
     if colorIndex < 0 { colorIndex = 0 }
     ```
   - In `MarginNoteTheme.swift`, ensure `cardPastels` handles all 16 MarginNote color indices cleanly (or modulo with rich palette).
   - Both the PDF highlight line annotations and the MindMap note cards (`CardNodeView`) must use `MarginNoteTheme.cardColors(for: card.colorIndex)`.
   - Changing the card color via the editor or toolbar updates both the card on the mindmap and the highlight color on the PDF.
