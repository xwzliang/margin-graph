# Phase 1: Project Foundation, Core Models, SQLite Storage, and MarginNote 3 Importer

## Overview
We are building **MarginGraph**, a native macOS app reproducing the full reading, excerpting, mindmap, outline, and flashcard functionality of MarginNote 3.
In this first phase, establish the SPM package foundation, core data models, high-performance SQLite storage layer, Spaced Repetition (SRS) engine, and a direct importer for existing MarginNote 3 databases (`MarginNotes.sqlite`).

## Acceptance Criteria
1. **Swift Package Configuration (`Package.swift`)**:
   - Swift tools version: 6.0 (or 5.9+ compatible).
   - Target macOS platform: `.macOS(.v14)` or `.macOS(.v15)`.
   - Targets:
     - `MarginGraphCore`: library target containing models, database, importer, and SRS engine.
     - `MarginGraphApp`: executable target containing the macOS SwiftUI/AppKit app entry point.
     - `MarginGraphCoreTests`: test target for `MarginGraphCore`.
   - Uses native `SQLite3` (`import SQLite3` from the macOS SDK) or zero external dependencies for storage, ensuring instant builds.

2. **Core Models (`Sources/MarginGraphCore/Models.swift`)**:
   - `Document`: `id: UUID`, `title: String`, `filePath: String`, `md5: String`, `totalPages: Int`, `lastVisited: Date?`.
   - `Topic` (Notebook / Study Set): `id: UUID`, `title: String`, `bookMD5List: [String]`, `createdAt: Date`, `updatedAt: Date`.
   - `HighlightRect`: `page: Int`, `x: Double`, `y: Double`, `width: Double`, `height: Double`.
   - `NoteCard`:
     - `id: UUID`
     - `topicId: UUID`
     - `bookMD5: String?`
     - `title: String`
     - `highlightText: String`
     - `notesText: String`
     - `groupNoteId: UUID?` (hierarchical parent note in MindMap/Outline)
     - `mindPos: CGPoint?` (coordinate on the 2D infinite canvas)
     - `mindLinks: [UUID]` (inter-card relationship links)
     - `isFolded: Bool`
     - `startPage: Int?`, `endPage: Int?`
     - `startPos: CGPoint?`, `endPos: CGPoint?`
     - `colorIndex: Int`
     - `tags: [String]`
     - `highlightPicHash: String?`
     - `createdAt: Date`, `updatedAt: Date`
   - `CardLink`: `id: UUID`, `topicId: UUID`, `sourceCardId: UUID`, `targetCardId: UUID`, `label: String?`, `isBidirectional: Bool`.
   - `ReviewItem`: `cardId: UUID`, `easeFactor: Double`, `intervalDays: Int`, `repetitions: Int`, `dueDate: Date`, `lastReviewed: Date?`.

3. **SQLite Database Layer (`Sources/MarginGraphCore/Database.swift`)**:
   - Manages an SQLite database file at a specified URL or in-memory (`:memory:` for tests).
   - Initializes tables: `documents`, `topics`, `cards`, `card_links`, `review_items`.
   - Provides thread-safe CRUD methods:
     - Document: `insertDocument`, `getDocument(id:)`, `getDocumentByMD5(md5:)`, `allDocuments()`.
     - Topic: `insertTopic`, `updateTopic`, `deleteTopic`, `getTopic(id:)`, `allTopics()`.
     - NoteCard: `insertCard`, `updateCard`, `deleteCard`, `getCard(id:)`, `cardsForTopic(id:)`, `childCards(parentId:topicId:)`.
     - CardLink: `insertLink`, `deleteLink`, `linksForTopic(id:)`.
     - ReviewItem: `upsertReviewItem`, `dueReviewItems(asOf:)`.

4. **Spaced Repetition System Engine (`Sources/MarginGraphCore/SRSEngine.swift`)**:
   - SuperMemo SM-2 algorithm:
     - Rating grade: 0 (blackout) to 5 (perfect recall). (Or standard 4-button: Again/Hard/Good/Easy).
     - Computes updated `easeFactor` (minimum 1.3), `repetitions`, `intervalDays`, and next `dueDate`.

5. **MarginNote 3 Importer (`Sources/MarginGraphCore/MarginNoteImporter.swift`)**:
   - Reads a MarginNote 3 `MarginNotes.sqlite` CoreData database:
     - Queries `ZTOPIC` -> imports into `Topic`.
     - Queries `ZBOOK` -> imports into `Document`.
     - Queries `ZBOOKNOTE` -> imports into `NoteCard` (parsing `ZMINDPOS`, `ZMINDLINKS`, `ZGROUPNOTEID`, `ZHIGHLIGHT_TEXT`, `ZNOTES_TEXT`, `ZNOTETITLE`).
   - Supports importing directly into the `MarginGraphCore.Database`.

6. **Minimal App Shell (`Sources/MarginGraphApp/MarginGraphApp.swift`)**:
   - SwiftUI `@main` `App` entry point displaying the app window with a sidebar listing notebooks and documents.

7. **Unit Tests (`Tests/MarginGraphCoreTests/`)**:
   - `DatabaseTests.swift`: verifies table creation, card insertion, updating positions, tree hierarchy queries, and link associations.
   - `SRSEngineTests.swift`: verifies SM-2 calculation intervals and ease factor adjustments.
   - `MarginNoteImporterTests.swift`: verifies importing mock MarginNote SQLite schemas and extracting topics, cards, and parent relationships.
